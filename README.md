# vibe-video

用「感觉流 + AI 生成」的方式做短视频的工作区。

## 目录

| 目录 | 放什么 |
| --- | --- |
| `ideas/` | 选题、灵感、竞品链接、爆点拆解 |
| `scripts/` | 分镜脚本、旁白、节奏表（一个项目一个 md） |
| `prompts/` | 出图 / 出视频 / 配音的 prompt，按镜头编号 |
| `assets/refs/` | 风格参考图、配色板、参考视频截帧 |
| `assets/images/` | 生成的静帧 |
| `assets/video/` | 生成的视频片段（未剪辑） |
| `assets/audio/` | 配音、BGM、音效 |
| `render/` | ffmpeg / 剪辑软件导出的成片 |
| `logs/` | 每期产出记录：用了什么模型、什么参数、哪版最好 |

## 一个项目的命名约定

```
<日期>-<短标题>/          例如 2026-11-05-深夜便利店
  brief.md                这一期想让人记住什么
  script.md               分镜
  prompts/                S01.md S02.md ...
  assets/                 素材
  render/v1.mp4           成片
```

## 工作流（草案）

1. **选题**：`ideas/` 里记一句话钩子 + 为什么有人看。
2. **脚本**：`script.md` 写到「每个镜头看得见什么、几秒」为止，不写散文。
3. **出图/出片**：prompt 按镜头编号，参数写在同文件末尾。
4. **配音**：先定总时长，再配 BGM。
5. **剪**：ffmpeg 拼 + 字幕，或导入剪映。
6. **复盘**：`logs/` 记一版结论，下期直接用。

## 技术路线

不是 AI 出图出片，是**跑代码生成画面**。两条已跑通：

- `demo-a/` — Canvas 逐帧 + 截图 + ffmpeg（抽象/氛围/循环）
- `demo-b/` — Remotion，React 写时间轴（排版/字卡/叙事）

对比与坑：`logs/2026-11-04-demo-compare.md`
